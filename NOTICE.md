# Notice

## Project lineage

Claude Code on Copilot began as a fork of [samarth777/claude-code-copilot](https://github.com/samarth777/claude-code-copilot), created by Samarth ([@samarth777](https://github.com/samarth777)).

The original repository has had no commits since February 2026, and [samarth777/claude-code-copilot#6](https://github.com/samarth777/claude-code-copilot/pull/6), which offered this work upstream in July 2026, received no response. Development therefore continues here as an independent project under a new name, with the full commit history preserved. The previous fork, [andyzengmath/claude-code-copilot](https://github.com/andyzengmath/claude-code-copilot), is archived and keeps the earlier pull requests and their reviews.
